### 3. 政策对比功能 ⚖️

**功能描述**：智能三级联动的政策对比系统

**核心特性**：
- ✅ 三级联动选择
  - 省份选择
  - 城市选择（根据省份动态加载）
  - 区县选择（根据城市动态加载）
- ✅ 全国覆盖
  - 23个省
  - 5个自治区
  - 4个直辖市
  - 所有下辖市区县
- ✅ 任意组合对比
  - 地区A和地区B可任意选择
  - 支持跨省对比
- ✅ 智能数据匹配
  - 自动查找最接近的政策数据
  - 无数据时显示友好提示
- ✅ 对比内容
  - 婚假天数
  - 产假天数
  - 育儿假天数
  - 陪产假天数
  - 生育补贴（一孩/二孩/三孩）

**文件位置**：
- `js/script.js` - initCompare(), performCompare()
- `js/policy-helper.js` - 智能数据查找
- `index.html` - 对比弹窗HTML

**使用方法**：
1. 点击右侧"对比"按钮
2. 选择地区A：省 → 市 → 区县
3. 选择地区B：省 → 市 → 区县
4. 点击"开始对比"
5. 查看对比结果表格

- **原因**：浏览器缓存旧版本文件
- **解决方案**：强制刷新（Ctrl+F5）
