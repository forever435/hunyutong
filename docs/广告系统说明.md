## 💰 变现模式

### 模式1：广告位租赁
- 按月收费，固定价格
- 适合：大品牌、长期合作

### 模式2：按效果付费
- CPC（按点击）：¥0.5-2/点击
- CPM（按展示）：¥5-20/千次展示
- CPA（按行动）：¥10-100/预约或咨询

### 模式3：交易分成
- 电商类：成交额的5-15%
- 服务类：订单金额的3-10%

### 模式4：会员体系
- 普通商家：¥1000/月，基础展示
- 银牌商家：¥3000/月，优先展示
- 金牌商家：¥5000/月，首页推荐

## 🚀 如何使用

### 对于网站管理员：
1. 商家联系后，编辑对应的HTML文件
2. 添加商家信息到数据数组中
3. 商家信息会自动显示在页面上

### 对于商家：
1. 访问 `ads/merchant-join.html` 查看入驻信息
2. 联系平台商务人员
3. 提交资质和广告素材
4. 审核通过后上线展示
